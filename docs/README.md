## 🎯 产品概述

一个企业级的前后端分离爬虫管理、数据采集平台，支持：

- ✅ **三种爬虫类型**：HTTP 爬虫、API 采集、浏览器自动化
- ✅ **可视化配置**：友好的配置界面，降低使用门槛
- ✅ **任务调度**：支持立即执行和定时任务
- ✅ **实时监控**：WebSocket 实时推送任务状态
- ✅ **数据管理**：数据查看、搜索、导出
- ✅ **权限管理**：基于角色的访问控制

---

## 🏗️ 技术架构

### 前端
- **框架**：React 18 + TypeScript
- **UI 库**：Ant Design 5.x
- **状态管理**：Zustand / Redux Toolkit
- **构建工具**：Vite

### 后端
- **框架**：Python FastAPI（推荐）或 Node.js NestJS
- **数据库**：SQLite
- **任务队列**：Celery + Redis 或 BullMQ + Redis
- **爬虫引擎**：Scrapy / Playwright / Puppeteer

### 基础设施
- **容器化**：Docker + Docker Compose
- **反向代理**：Nginx

## 🔄 三种爬虫类型对比

| 特性 | HTTP 爬虫 | API 采集 | 浏览器自动化 |
|------|-----------|---------|--------------|
| **适用场景** | 静态网页 | API 接口 | 动态网页 |
| **配置复杂度** | 低 | 中 | 高 |
| **执行速度** | 快 | 快 | 慢 |
| **反爬虫能力** | 弱 | 中 | 强 |
| **资源消耗** | 低 | 低 | 高 |
| **主要配置项** | URL、请求头、提取规则 | API 地址、认证、参数化 | 操作步骤、浏览器配置 |

## 🗄️ 数据库设计要点

- **使用 SQLite**：轻量级，适合中小型项目
- **核心表**：users, roles, crawlers, tasks, task_logs, crawl_data
- **配置存储**：使用 JSON 字段存储爬虫配置，灵活且易扩展
- **版本管理**：crawler_config_history 表记录配置历史
- **数据去重**：通过 data_hash 字段实现

详细设计请查看 [数据库设计文档](./数据库设计文档.md)

## 📝 交互流程示例

### HTTP 爬虫创建流程
1. 选择爬虫类型 → 通用爬虫（HTTP）
2. 填写基础信息（名称、URL）
3. 配置请求（请求头、Cookie、代理）
4. 配置数据提取规则（XPath/CSS 选择器）
5. 配置分页规则
6. 配置反爬虫策略
7. 测试配置
8. 保存并创建任务

### API 采集流程
1. 选择爬虫类型 → API 采集
2. 配置 API 接口（URL、请求方式）
3. 配置认证（API Key/Bearer Token）
4. 配置参数化（参数来源和值）
5. 配置数据提取（JSONPath）
6. 配置请求频率限制
7. 测试 API
8. 保存并创建任务

### 浏览器自动化流程
1. 选择爬虫类型 → 浏览器自动化
2. 配置浏览器（类型、模式）
3. 配置操作步骤（录制或手动配置）
4. 配置数据提取
5. 配置分页规则
6. 配置错误处理
7. 调试测试
8. 保存并创建任务

详细流程请查看 [爬虫管理模块详细设计](./爬虫管理模块详细设计.md)
