# 数据库设计文档（SQLite）

## 一、数据库概述

使用 SQLite 作为主数据库，存储所有结构化数据。采集的原始数据也存储在 SQLite 中，通过分表或 JSON 字段存储。

---

## 二、核心表结构设计

### 2.1 用户表（users）

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL UNIQUE,          -- 用户名
    email TEXT NOT NULL UNIQUE,             -- 邮箱
    password_hash TEXT NOT NULL,            -- 密码哈希
    full_name TEXT,                         -- 全名
    avatar_url TEXT,                        -- 头像 URL
    role_id INTEGER,                        -- 角色 ID（外键）
    status TEXT DEFAULT 'active',           -- 状态: active/inactive
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    last_login_at DATETIME                  -- 最后登录时间
);

CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_role_id ON users(role_id);
```

### 2.2 角色表（roles）

```sql
CREATE TABLE roles (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,              -- 角色名称: admin/developer/viewer
    display_name TEXT NOT NULL,             -- 显示名称
    description TEXT,                        -- 角色描述
    permissions TEXT,                        -- JSON 格式的权限列表
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 初始化默认角色
INSERT INTO roles (name, display_name, description, permissions) VALUES
('admin', '管理员', '拥有所有权限', '["*"]'),
('developer', '开发者', '可以创建和管理爬虫', '["crawler:create", "crawler:edit", "crawler:delete", "task:create", "task:view"]'),
('viewer', '查看者', '只能查看数据', '["crawler:view", "task:view", "data:view"]');
```

### 2.3 爬虫配置表（crawlers）

```sql
CREATE TABLE crawlers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                     -- 爬虫名称
    description TEXT,                       -- 描述
    type TEXT NOT NULL,                     -- 类型: http/api/browser
    status TEXT DEFAULT 'inactive',         -- 状态: active/inactive/error
    config TEXT NOT NULL,                   -- JSON 格式的完整配置
    tags TEXT,                              -- JSON 数组，标签列表
    created_by INTEGER,                     -- 创建人 ID（外键）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    version INTEGER DEFAULT 1,              -- 配置版本号
    is_template INTEGER DEFAULT 0,          -- 是否为模板: 0/1
    template_category TEXT,                 -- 模板分类（如果是模板）
    
    FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL
);

CREATE INDEX idx_crawlers_type ON crawlers(type);
CREATE INDEX idx_crawlers_status ON crawlers(status);
CREATE INDEX idx_crawlers_created_by ON crawlers(created_by);
CREATE INDEX idx_crawlers_is_template ON crawlers(is_template);
```

### 2.4 爬虫配置历史表（crawler_config_history）

```sql
CREATE TABLE crawler_config_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    crawler_id INTEGER NOT NULL,            -- 爬虫 ID（外键）
    config TEXT NOT NULL,                   -- 历史配置 JSON
    version INTEGER NOT NULL,               -- 版本号
    change_note TEXT,                       -- 变更说明
    created_by INTEGER,                     -- 创建人 ID
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (crawler_id) REFERENCES crawlers(id) ON DELETE CASCADE,
    FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL
);

CREATE INDEX idx_crawler_config_history_crawler_id ON crawler_config_history(crawler_id);
CREATE INDEX idx_crawler_config_history_version ON crawler_config_history(crawler_id, version);
```

### 2.5 任务表（tasks）

```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    crawler_id INTEGER NOT NULL,            -- 爬虫 ID（外键）
    name TEXT NOT NULL,                     -- 任务名称
    status TEXT DEFAULT 'pending',          -- 状态: pending/running/completed/failed/cancelled
    schedule_type TEXT DEFAULT 'manual',     -- 调度类型: manual/cron/once
    cron_expression TEXT,                   -- Cron 表达式（如果是定时任务）
    execute_at DATETIME,                    -- 计划执行时间
    started_at DATETIME,                    -- 实际开始时间
    completed_at DATETIME,                  -- 完成时间
    duration INTEGER,                        -- 执行时长（秒）
    total_items INTEGER DEFAULT 0,          -- 总采集项数
    success_items INTEGER DEFAULT 0,         -- 成功项数
    failed_items INTEGER DEFAULT 0,          -- 失败项数
    error_message TEXT,                     -- 错误信息
    config_overrides TEXT,                  -- JSON 格式的任务配置覆盖（可选）
    created_by INTEGER,                     -- 创建人 ID
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (crawler_id) REFERENCES crawlers(id) ON DELETE CASCADE,
    FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL
);

CREATE INDEX idx_tasks_crawler_id ON tasks(crawler_id);
CREATE INDEX idx_tasks_status ON tasks(status);
CREATE INDEX idx_tasks_created_by ON tasks(created_by);
CREATE INDEX idx_tasks_execute_at ON tasks(execute_at);
CREATE INDEX idx_tasks_created_at ON tasks(created_at);
```

### 2.6 任务日志表（task_logs）

```sql
CREATE TABLE task_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id INTEGER NOT NULL,               -- 任务 ID（外键）
    level TEXT NOT NULL,                    -- 日志级别: DEBUG/INFO/WARNING/ERROR
    message TEXT NOT NULL,                  -- 日志消息
    details TEXT,                           -- JSON 格式的详细信息
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (task_id) REFERENCES tasks(id) ON DELETE CASCADE
);

CREATE INDEX idx_task_logs_task_id ON task_logs(task_id);
CREATE INDEX idx_task_logs_level ON task_logs(level);
CREATE INDEX idx_task_logs_created_at ON task_logs(created_at);
```

### 2.7 采集数据表（crawl_data）

**方案一：单表存储（适合数据量不大的场景）**

```sql
CREATE TABLE crawl_data (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    crawler_id INTEGER NOT NULL,            -- 爬虫 ID（外键）
    task_id INTEGER NOT NULL,               -- 任务 ID（外键）
    data TEXT NOT NULL,                     -- JSON 格式的采集数据
    data_hash TEXT,                         -- 数据哈希值（用于去重）
    url TEXT,                               -- 数据来源 URL
    status TEXT DEFAULT 'success',          -- 状态: success/failed
    error_message TEXT,                     -- 错误信息（如果失败）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (crawler_id) REFERENCES crawlers(id) ON DELETE CASCADE,
    FOREIGN KEY (task_id) REFERENCES tasks(id) ON DELETE CASCADE
);

CREATE INDEX idx_crawl_data_crawler_id ON crawl_data(crawler_id);
CREATE INDEX idx_crawl_data_task_id ON crawl_data(task_id);
CREATE INDEX idx_crawl_data_data_hash ON crawl_data(data_hash);
CREATE INDEX idx_crawl_data_created_at ON crawl_data(created_at);
```

**方案二：分表存储（适合数据量大的场景）**

为每个爬虫创建独立的数据表，表名格式：`crawl_data_{crawler_id}`

```sql
-- 动态创建表的 SQL 模板
CREATE TABLE crawl_data_{crawler_id} (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id INTEGER NOT NULL,
    data TEXT NOT NULL,
    data_hash TEXT,
    url TEXT,
    status TEXT DEFAULT 'success',
    error_message TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (task_id) REFERENCES tasks(id) ON DELETE CASCADE
);

CREATE INDEX idx_crawl_data_{crawler_id}_task_id ON crawl_data_{crawler_id}(task_id);
CREATE INDEX idx_crawl_data_{crawler_id}_data_hash ON crawl_data_{crawler_id}(data_hash);
CREATE INDEX idx_crawl_data_{crawler_id}_created_at ON crawl_data_{crawler_id}(created_at);
```

### 2.8 数据源表（data_sources）

用于存储数据源配置，支持从多个数据源采集数据。

```sql
CREATE TABLE data_sources (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                     -- 数据源名称
    type TEXT NOT NULL,                     -- 类型: database/api/file
    config TEXT NOT NULL,                   -- JSON 格式的配置
    description TEXT,                       -- 描述
    created_by INTEGER,                     -- 创建人 ID
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL
);

CREATE INDEX idx_data_sources_type ON data_sources(type);
```

### 2.9 告警配置表（alerts）

```sql
CREATE TABLE alerts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                     -- 告警名称
    type TEXT NOT NULL,                     -- 类型: task_failed/task_slow/data_empty
    condition TEXT NOT NULL,                -- JSON 格式的告警条件
    notification_channels TEXT NOT NULL,    -- JSON 数组，通知渠道: email/webhook/sms
    enabled INTEGER DEFAULT 1,             -- 是否启用: 0/1
    crawler_id INTEGER,                     -- 关联的爬虫 ID（可选）
    created_by INTEGER,                     -- 创建人 ID
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (crawler_id) REFERENCES crawlers(id) ON DELETE CASCADE,
    FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL
);

CREATE INDEX idx_alerts_enabled ON alerts(enabled);
CREATE INDEX idx_alerts_crawler_id ON alerts(crawler_id);
```

### 2.10 告警记录表（alert_records）

```sql
CREATE TABLE alert_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    alert_id INTEGER NOT NULL,              -- 告警配置 ID（外键）
    task_id INTEGER,                        -- 关联的任务 ID（可选）
    level TEXT NOT NULL,                    -- 告警级别: info/warning/critical
    title TEXT NOT NULL,                    -- 告警标题
    message TEXT NOT NULL,                  -- 告警消息
    status TEXT DEFAULT 'pending',          -- 状态: pending/sent/failed
    sent_at DATETIME,                       -- 发送时间
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (alert_id) REFERENCES alerts(id) ON DELETE CASCADE,
    FOREIGN KEY (task_id) REFERENCES tasks(id) ON DELETE SET NULL
);

CREATE INDEX idx_alert_records_alert_id ON alert_records(alert_id);
CREATE INDEX idx_alert_records_status ON alert_records(status);
CREATE INDEX idx_alert_records_created_at ON alert_records(created_at);
```

### 2.11 系统配置表（system_configs）

```sql
CREATE TABLE system_configs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    key TEXT NOT NULL UNIQUE,               -- 配置键
    value TEXT NOT NULL,                    -- 配置值（JSON 格式）
    description TEXT,                       -- 配置描述
    category TEXT,                          -- 配置分类
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_by INTEGER,                     -- 更新人 ID
    
    FOREIGN KEY (updated_by) REFERENCES users(id) ON DELETE SET NULL
);

CREATE INDEX idx_system_configs_key ON system_configs(key);
CREATE INDEX idx_system_configs_category ON system_configs(category);
```

### 2.12 操作审计表（audit_logs）

```sql
CREATE TABLE audit_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,                        -- 操作用户 ID
    action TEXT NOT NULL,                   -- 操作类型: create/update/delete/execute
    resource_type TEXT NOT NULL,            -- 资源类型: crawler/task/user
    resource_id INTEGER,                    -- 资源 ID
    details TEXT,                           -- JSON 格式的操作详情
    ip_address TEXT,                        -- IP 地址
    user_agent TEXT,                        -- User Agent
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE SET NULL
);

CREATE INDEX idx_audit_logs_user_id ON audit_logs(user_id);
CREATE INDEX idx_audit_logs_resource ON audit_logs(resource_type, resource_id);
CREATE INDEX idx_audit_logs_created_at ON audit_logs(created_at);
```

## 五、数据迁移策略

### 5.1 版本管理
使用 `schema_version` 表记录数据库版本：

```sql
CREATE TABLE schema_version (
    version INTEGER PRIMARY KEY,
    applied_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    description TEXT
);
```

### 5.2 迁移脚本
每次数据库结构变更时，创建迁移脚本文件，命名格式：`migration_YYYYMMDD_HHMMSS.sql`

## 六、性能优化建议

1. **索引优化**：为常用查询字段创建索引
2. **数据归档**：定期归档旧数据到归档表
3. **分表策略**：数据量大时，按时间或爬虫 ID 分表
4. **JSON 字段查询**：SQLite 3.38+ 支持 JSON 函数，可以查询 JSON 字段
5. **连接池**：使用连接池管理数据库连接
6. **批量操作**：使用事务批量插入数据

---

## 七、数据备份与恢复

1. **定期备份**：使用 SQLite 的 `.backup` 命令定期备份
2. **增量备份**：记录 WAL（Write-Ahead Logging）文件
3. **数据导出**：支持导出为 SQL 文件或 CSV 文件
