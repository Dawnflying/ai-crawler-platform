# 爬虫管理模块详细设计文档

## 一、模块概述

爬虫管理模块是平台的核心模块，负责爬虫的创建、配置、测试、管理和执行。支持三种爬虫类型，每种类型有独特的配置方式和交互流程。

---

## 二、爬虫类型定义

### 2.1 通用爬虫（HTTP 爬虫）
**适用场景：**
- 静态网页数据采集
- RESTful API 数据获取
- 简单的动态内容（通过 Ajax 请求获取）

**技术实现：**
- 基于 HTTP 请求（GET/POST）
- 支持请求头、Cookie、代理配置
- 支持 XPath、CSS 选择器、正则表达式提取数据

### 2.2 API 采集爬虫
**适用场景：**
- 调用第三方 API 接口
- 批量 API 请求
- 需要参数化请求的场景

**技术实现：**
- 直接调用 API 接口
- 支持参数模板和动态参数
- 支持认证（API Key、OAuth、Bearer Token）
- 支持请求频率限制

### 2.3 浏览器自动化爬虫
**适用场景：**
- JavaScript 渲染的动态网页
- 需要模拟用户操作（点击、滚动、输入）
- 需要处理 Cookie、Session
- 反爬虫较强的网站

**技术实现：**
- 基于 Playwright / Puppeteer
- 支持浏览器操作录制和回放
- 支持等待元素加载
- 支持截图和调试

## 三、产品交互流程设计

### 3.1 通用爬虫（HTTP 爬虫）交互流程

#### 3.1.1 创建流程

**步骤 1：选择爬虫类型**
- 用户点击"创建爬虫"按钮
- 弹出类型选择弹窗，显示三种类型卡片
- 用户选择"通用爬虫（HTTP）"

**步骤 2：基础信息配置**
```
表单字段：
- 爬虫名称*（必填）
- 爬虫描述
- 分类标签（可选，用于分组）
- 目标网站 URL*（必填，支持多个 URL，每行一个）
```

**步骤 3：请求配置**
```
请求方式：GET / POST / PUT / DELETE（下拉选择）
请求 URL：自动填充或手动输入

请求头配置：
- 表格形式展示，可添加多行
- 常用请求头快捷添加（User-Agent、Accept、Referer 等）
- 支持变量替换（如：{{user_agent}}）

Cookie 配置：
- 方式一：手动输入 Cookie 字符串
- 方式二：从浏览器导入（粘贴 Cookie）
- 方式三：自动管理（平台自动维护）

请求体配置（POST 请求时显示）：
- 格式选择：JSON / Form-Data / Raw
- 内容编辑器（支持语法高亮）
- 支持变量替换

代理配置：
- 不使用代理
- 使用代理池（从平台代理池选择）
- 自定义代理（单个代理地址）
```

**步骤 4：数据提取规则配置**
```
提取模式：结构化提取 / 自定义脚本

模式一：结构化提取（可视化配置）
- 添加提取字段
- 字段名称、字段类型（文本/数字/日期/链接/图片）
- 提取方式：XPath / CSS 选择器 / 正则表达式
- 提取表达式输入框
- 实时预览提取结果（点击"测试提取"按钮）

模式二：自定义脚本（高级模式）
- 代码编辑器（支持 Python/JavaScript）
- 提供常用函数库
- 脚本调试工具
```

**步骤 5：分页/翻页配置**
```
是否需要分页：是 / 否

分页方式：
- URL 参数分页（如：?page=1, ?page=2）
- URL 路径分页（如：/page/1, /page/2）
- 点击"下一页"按钮
- 滚动加载（无限滚动）

分页配置：
- 起始页码
- 结束页码（或最大页数）
- 页码增量
```

**步骤 6：反爬虫策略**
```
请求频率控制：
- 请求间隔（秒）：固定间隔 / 随机间隔（范围）
- 并发数限制

User-Agent 轮换：
- 使用默认 UA 池
- 自定义 UA 列表

重试策略：
- 最大重试次数
- 重试间隔
- 重试条件（HTTP 状态码、超时等）
```

**步骤 7：数据存储配置**
```
存储方式：
- 仅存储到数据库
- 存储并导出文件（CSV/JSON/Excel）

数据去重：
- 基于字段去重（选择唯一字段）
- 基于 URL 去重

数据验证：
- 字段必填验证
- 数据格式验证（正则表达式）
```

**步骤 8：测试与保存**
```
测试功能：
- "测试请求"按钮：测试 HTTP 请求是否成功
- "测试提取"按钮：测试数据提取规则是否正确
- "预览数据"按钮：显示提取的数据预览

保存选项：
- 保存并立即创建任务
- 仅保存配置（稍后创建任务）
```

#### 3.1.2 编辑流程
- 与创建流程相同，但表单预填充已有配置
- 支持配置版本历史查看和回滚

#### 3.1.3 执行流程
```
1. 用户点击"执行"按钮
2. 弹出执行配置弹窗：
   - 执行方式：立即执行 / 定时执行
   - 执行参数（如：起始页码、URL 列表等）
3. 创建任务并加入任务队列
4. 跳转到任务详情页，实时查看执行状态
```

### 3.2 API 采集爬虫交互流程

#### 3.2.1 创建流程

**步骤 1：选择爬虫类型**
- 用户选择"API 采集爬虫"

**步骤 2：基础信息配置**
```
表单字段：
- 爬虫名称*
- 爬虫描述
- API 文档链接（可选，用于参考）
```

**步骤 3：API 接口配置**
```
请求方式：GET / POST / PUT / DELETE
API 地址*：https://api.example.com/v1/data

路径参数（Path Parameters）：
- 表格形式，参数名和参数值
- 支持变量替换（如：{{id}}）

查询参数（Query Parameters）：
- 表格形式，参数名和参数值
- 支持变量替换
- 支持从数据源获取（如：从上一个 API 响应中提取）
```

**步骤 4：认证配置**
```
认证方式：
- 无需认证
- API Key（Header / Query）
- Bearer Token
- OAuth 2.0
- Basic Auth
- 自定义 Header

配置示例（API Key）：
- Key 名称：X-API-Key
- Key 位置：Header
- Key 值：{{api_key}}（支持变量）
```

**步骤 5：请求体配置（POST/PUT 时显示）**
```
请求体格式：JSON / Form-Data / XML

JSON 模板编辑器：
- 可视化 JSON 编辑器
- 支持变量替换
- 支持从数据源动态填充

示例：
{
  "page": {{page_num}},
  "limit": 20,
  "filter": {
    "status": "active"
  }
}
```

**步骤 6：参数化配置**
```
参数来源：
- 静态列表（手动输入）
- 从文件导入（CSV/JSON）
- 从数据库查询
- 从其他 API 获取

参数模板：
- 定义参数变量（如：{{city_id}}）
- 配置参数值来源
- 支持参数组合（笛卡尔积）

示例：
参数：city_id
值来源：静态列表 [1, 2, 3, 4, 5]
结果：会为每个 city_id 发起一次 API 请求
```

**步骤 7：数据提取与转换**
```
响应格式：JSON / XML / Text

JSON 提取：
- JSONPath 表达式提取
- 可视化路径选择器
- 数据映射配置

数据转换：
- 字段重命名
- 数据类型转换
- 数据清洗规则（去除空格、格式化日期等）
- 数据合并（多个字段合并为一个）
```

**步骤 8：请求频率控制**
```
频率限制：
- 每秒请求数（QPS）
- 每分钟请求数
- 每小时请求数
- 自定义限制规则

限流策略：
- 固定延迟
- 令牌桶算法
- 漏桶算法
```

**步骤 9：错误处理**
```
错误重试：
- 最大重试次数
- 重试间隔
- 重试条件（HTTP 状态码、超时）

错误处理：
- 记录错误日志
- 跳过错误继续执行
- 停止任务
```

**步骤 10：测试与保存**
```
测试功能：
- "测试 API"按钮：测试单个 API 请求
- "测试参数化"按钮：测试参数化请求
- "预览响应"按钮：查看 API 响应数据
- "验证数据"按钮：验证数据提取规则

保存选项：
- 保存并立即创建任务
- 仅保存配置
```

#### 3.2.2 批量 API 采集流程
```
场景：需要调用多个不同的 API 接口

配置方式：
1. 添加多个 API 端点
2. 配置每个端点的参数和认证
3. 配置执行顺序（串行/并行）
4. 配置数据合并规则（如何合并多个 API 的数据）
```

### 3.3 浏览器自动化爬虫交互流程

#### 3.3.1 创建流程

**步骤 1：选择爬虫类型**
- 用户选择"浏览器自动化爬虫"

**步骤 2：基础信息配置**
```
表单字段：
- 爬虫名称*
- 爬虫描述
- 目标网站 URL*
```

**步骤 3：浏览器配置**
```
浏览器类型：Chrome / Firefox / Safari / Edge
浏览器模式：
- 有头模式（可见浏览器窗口，用于调试）
- 无头模式（后台运行，用于生产）

浏览器选项：
- 窗口大小（宽度 x 高度）
- User-Agent
- 语言设置
- 禁用图片加载（加速）
- 禁用 JavaScript（可选）
```

**步骤 4：操作流程配置（核心）**

**方式一：可视化操作录制**
```
1. 点击"开始录制"按钮
2. 打开浏览器窗口（Playwright 控制）
3. 用户手动操作浏览器：
   - 访问 URL
   - 点击元素
   - 输入文本
   - 滚动页面
   - 等待元素出现
   - 提取数据
4. 系统自动记录操作步骤
5. 点击"停止录制"
6. 生成操作步骤列表（可编辑）
```

**方式二：手动配置操作步骤**
```
操作步骤列表（可拖拽排序）：

步骤类型：
1. 访问页面（Navigate）
   - URL（支持变量）
   - 等待条件（加载完成/元素出现）

2. 点击元素（Click）
   - 元素选择器（CSS/XPath）
   - 等待时间（点击后等待）
   - 等待元素出现（可选）

3. 输入文本（Input）
   - 元素选择器
   - 输入内容（支持变量）
   - 清空后输入 / 追加

4. 滚动页面（Scroll）
   - 滚动方向（向下/向上/到元素）
   - 滚动距离 / 目标元素

5. 等待（Wait）
   - 等待时间（秒）
   - 等待元素出现
   - 等待网络请求完成

6. 提取数据（Extract）
   - 字段名称
   - 元素选择器
   - 提取方式（文本/属性/HTML）
   - 数据验证规则

7. 循环操作（Loop）
   - 循环条件（元素列表/固定次数）
   - 循环内的操作步骤

8. 条件判断（If）
   - 判断条件（元素存在/文本匹配）
   - 条件成立时的操作
   - 条件不成立时的操作

9. 执行 JavaScript（Execute Script）
   - JavaScript 代码
   - 返回值处理

操作步骤编辑器界面：
- 左侧：操作步骤列表（树形结构）
- 右侧：当前步骤的详细配置
- 支持拖拽排序、复制、删除
- 支持步骤分组和折叠
```

**步骤 5：数据提取配置**
```
提取模式：
- 在操作步骤中提取（推荐）
- 单独配置提取规则

提取规则：
- 字段名称
- 元素选择器（CSS/XPath）
- 提取方式：
  * 文本内容
  * HTML 内容
  * 属性值（href、src、data-* 等）
  * 多个元素（列表）
- 数据清洗规则
- 数据验证规则
```

**步骤 6：分页/翻页配置**
```
分页方式：
- 点击"下一页"按钮
- 滚动加载（无限滚动）
- URL 变化（动态 URL）

分页配置：
- 下一页按钮选择器
- 最大页数 / 最大滚动次数
- 停止条件（元素不存在/数据重复）
```

**步骤 7：Cookie 和 Session 管理**
```
Cookie 管理：
- 自动管理（浏览器自动处理）
- 手动导入 Cookie
- 登录流程录制（自动获取 Cookie）

Session 保持：
- 保持登录状态
- Cookie 持久化存储
```

**步骤 8：反爬虫策略**
```
策略配置：
- 随机延迟（操作间隔随机化）
- 模拟人类行为（随机鼠标移动、滚动）
- 请求头伪装
- 代理使用

验证码处理：
- 手动处理（暂停等待）
- 第三方验证码识别服务集成
- 跳过验证码页面
```

**步骤 9：错误处理与重试**
```
错误处理：
- 元素未找到：重试 / 跳过 / 停止
- 页面加载超时：重试 / 跳过
- JavaScript 错误：记录日志 / 停止

重试策略：
- 最大重试次数
- 重试间隔
- 重试条件
```

**步骤 10：调试与测试**
```
调试工具：
- "单步执行"：逐步执行操作步骤
- "执行到此处"：执行到指定步骤
- "截图调试"：每个步骤自动截图
- "查看控制台"：查看浏览器控制台日志

测试功能：
- "测试执行"：完整执行一次流程
- "预览数据"：查看提取的数据
- "性能分析"：查看执行时间和资源消耗
```

**步骤 11：保存与执行**
```
保存选项：
- 保存配置
- 保存并创建任务

执行配置：
- 执行方式：立即执行 / 定时执行
- 并发数（多个浏览器实例）
- 执行环境（本地/远程浏览器）
```

## 六、数据模型设计

### 6.1 爬虫配置表（crawlers）
```sql
CREATE TABLE crawlers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                    -- 爬虫名称
    description TEXT,                      -- 描述
    type TEXT NOT NULL,                    -- 类型: http/api/browser
    status TEXT DEFAULT 'inactive',        -- 状态: active/inactive/error
    config TEXT NOT NULL,                  -- JSON 配置（存储详细配置）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    created_by INTEGER,                    -- 创建人 ID
    version INTEGER DEFAULT 1              -- 配置版本号
);
```

### 6.2 配置 JSON 结构示例

**通用爬虫配置：**
```json
{
  "type": "http",
  "base_url": "https://example.com",
  "method": "GET",
  "headers": {
    "User-Agent": "Mozilla/5.0..."
  },
  "cookies": "",
  "proxy": {
    "enabled": false,
    "type": "pool"
  },
  "extract_rules": [
    {
      "field": "title",
      "selector": "h1",
      "type": "css",
      "data_type": "text"
    }
  ],
  "pagination": {
    "enabled": true,
    "type": "url_param",
    "param": "page",
    "start": 1,
    "end": 10
  },
  "anti_crawl": {
    "delay": {
      "min": 1,
      "max": 3
    },
    "concurrent": 1
  }
}
```

**API 采集爬虫配置：**
```json
{
  "type": "api",
  "method": "GET",
  "url": "https://api.example.com/v1/data",
  "auth": {
    "type": "api_key",
    "key_name": "X-API-Key",
    "key_location": "header",
    "key_value": "{{api_key}}"
  },
  "params": {
    "path": {},
    "query": {
      "page": "{{page_num}}",
      "limit": 20
    }
  },
  "param_source": {
    "type": "static",
    "values": [1, 2, 3, 4, 5]
  },
  "extract": {
    "jsonpath": "$.data[*]"
  },
  "rate_limit": {
    "qps": 10
  }
}
```

**浏览器自动化爬虫配置：**
```json
{
  "type": "browser",
  "browser": "chrome",
  "headless": true,
  "viewport": {
    "width": 1920,
    "height": 1080
  },
  "steps": [
```

## 八、用户体验优化点

1. **配置向导**：分步骤引导用户完成配置，降低学习成本
2. **实时预览**：配置过程中实时预览效果，及时发现问题
3. **模板市场**：提供常用网站的爬虫模板，一键导入
4. **配置验证**：保存前自动验证配置完整性
5. **错误提示**：清晰的错误提示和修复建议
6. **操作录制**：浏览器自动化支持操作录制，降低配置难度
7. **配置导入导出**：支持 JSON 格式的配置导入导出
8. **配置版本管理**：保存配置历史，支持回滚
